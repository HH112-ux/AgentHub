## 1. 项目定位与目标

在开源中后台底座（RBAC、工作流、调度、文件存储、消息推送）之上，以 AgentScope Java 2.0.4 为智能体内核，构建**可运营、可审计、可控、可评测**的企业级 AI 业务运行平台：用户用自然语言提问，入口智能体「小Z」判断意图并路由到领域专家，专家在受控权限内调用工具与知识库完成作业，写操作经人工确认后落地。

- **一周目标**：交付一条可演示的完整业务闭环（§7），前端上线 Qoder Sites，服务端在云服务器可访问。
- **全量目标**：手册全部功能（6 大能力域、34 个功能页、98 按钮权限、40 张 `ai_` 表），按 §9 的 13 片阶梯滚动交付，全量承诺不变。

## 2. 部署形态（前端在哪里）

### 2.1 答案

| 层 | 部署位置 | 内容 |
|---|---|---|
| **前端** | **Qoder Sites** | Vue 3 构建产物：工作台、34 页管理台、站点门户、跳转链接 |
| 服务端 | 云服务器 | Spring Boot 单进程单 jar（含 AI 能力模块） |
| 数据与中间件 | 云服务器 | PostgreSQL 14（默认）/ MySQL 8.0、Redis ≥6、Milvus + etcd、MinIO 或云 OSS |
| 常驻能力 | 云服务器 | 应用内 60 秒调度、Reaper 中断回收、MCP 出口 `/mcp`、飞书/钉钉长连接外连 |
| 本地开发 | 开发机 | Vite dev server + proxy 指向云服务器 API；不在 Sites 上调试 |

### 2.2 拓扑

```
浏览器 ──HTTPS──▶ Qoder Sites（前端静态产物 + 门户 + 跳转链接）
                     │ HTTPS 跨域（CORS 白名单）
                     ▼
              云服务器（公网 IP + 域名 + 证书）
                Nginx：/prod-api 反代、SSE 长连接配置
                  ├─ 应用服务（Spring Boot）
                  ├─ PG 栈 :8080 ｜ MySQL 栈 :8081（双方言，可并存）
                  ├─ Redis（会话状态 / HITL 待确认 / 锁 / 限流 / 运行期配置）
                  ├─ Milvus + etcd（向量集合 + BM25 集合）
                  └─ 对象存储（附件 / 文档原文 / 大结果落盘）
```

### 2.3 跨站约束（违反即演示失败）

1. **API 必须 HTTPS**：Sites 页面为 HTTPS，调 HTTP 接口会被浏览器按混合内容拦截。证书是 D1 硬前置。
2. **CORS 白名单**：只放行 Sites 站点域名与本地开发域名，禁止 `*`。
3. **SSE 鉴权用一次性票据**：`EventSource` 不支持自定义请求头，不能直挂 `Authorization: Bearer`。先经普通鉴权接口换短时效 ticket（单次有效、绑定用户与会话），再以查询参数建流。
4. **渠道回调走云服务器**：飞书/企微/GitHub Webhook 需公网可达 + 验签/解密 + 渠道口令；长连接渠道由云服务器主动外连，免公网回调。
5. **MCP 出口在云服务器**：`/mcp`，Bearer 或专用口令，fail-closed，留空拒所有请求。
6. **密钥只在服务端**：模型密钥、渠道凭据、MCP 请求头密文落库；Sites 侧不放任何密钥。
7. **跳转链接**：门户 → 工作台 / 管理台 / 文档；管理页深链需鉴权回跳。

## 6. 接口与事件契约（A0 冻结，冻结后不改）

### 6.1 接口约定

- 路由 `/ai/{域}/{资源}`；每接口带 `ai:{模块}:{动作}` 权限标识并同步登记菜单脚本（98 按钮权限的前端显隐由此驱动）。
- 入参 Bo / 出参 Vo / 实体三层，MapStruct-Plus 映射；统一响应体沿用底座。
- 对话两步：先发送接口落库取稳定 `messageId`，再建流取回答；HITL 暂停轮用恢复接口继续；附件先暂存后绑定。
- 唯一免登录端点为渠道回调 `/ai/channel/callback/**`，安全由验签/解密/渠道口令承担。
- RSA 接口加解密需白名单，明确排除流式与文件流。

### 6.2 SSE 事件协议

每条事件携带 `type / sessionId / turnId / seq / payload`。事件类型：

| 类型 | 载荷要点 |
|---|---|
| 正文增量 | 文本片段 |
| 路由提示 | 自答 / 路由专家 / 已指定专家 |
| 专家起止 | 专家名、状态、重试次数、失败原因、原始结论 |
| 工具调用起止 | 工具名、来源标签、状态、耗时、入参、结果摘要 |
| 确认请求与处置 | 工具、入参、允许本次 / 记住该工具 / 拒绝 |
| 进度播报 | 思考 / 调用工具 / 咨询专家 / 汇总 |
| 参考来源 | 命中片段与出处 |
| 停止生成 | 中断原因 |
| 轮次结束 | 状态与用量 |

**硬约束**：确认卡片刷新后可还原 ⇒ 编排事件必须可持久化或可重建，落 `ai_message` 的编排事件快照字段。

### 6.3 工具与装配契约

- `ai_tool.impl_name` ↔ 代码侧工厂常量，是元数据与代码之间**唯一允许的引用面**；注册页不产生裸 SQL/Shell/HTTP 万能工具。
- 三档授权枚举：允许 / 需确认 / 禁止；优先级 会话直选 > 场景包 > 智能体绑定；禁止档在装配期不注册（模型不可见）。
- 装配缓存键：`智能体 × 会话资源集签名`；资源内容变更由装配指纹触发重建；改选择后下一轮生效。
- 降级必须带**结构化原因码**，否则"降级并如实声明"无法统一实现。
- 写工具：HITL 由档位驱动、执行期复核业务权限、操作人取自运行上下文（非线程上下文）、数据权限显式归属校验、无人值守默认拒绝、非幂等操作要求幂等键。

### 6.4 三层权限模型

① 工具可见面（装配期：智能体绑定 ∪ 会话资源集 ∪ 平台内置只读，禁止档不注册）→ ② 三档授权（运行期 ALLOW/ASK/DENY）→ ③ 业务权限复核（执行期按提问用户复核菜单权限）。

## 7. 一周交付：一条完整业务闭环

### 7.1 演示故事

运营在工作台问："把这条季度值班调整发成公告。"
小Z 判定意图 → 路由到行政公告专家 → 专家检索知识库、回答带来源卡片 → 调写工具 → **弹内联确认卡片** → 允许本次 → 公告落库、列表可见 → 审计页可查本轮编排运行、工具调用明细、权限决策。

一条故事压穿 11 个机制：登录、模型接入、会话/消息落库、SSE 流式、入口路由、专家装配缓存、检索与上下文装配、工具两段式、三档授权、HITL 暂停/恢复、三类审计留痕。

### 7.2 范围

- **建**：PG 单栈、18 张表（§5 加粗）、6 个前端页（工作台 / 模型配置 / 专家配置含小Z / 知识库含文档与检索测试 / 工具注册 / 审计三页签合一）。
- **A0 本周为压缩形态**：18 表 + 本片用到的事件类型与接口子集；双方言脚本同步维护不推后；命名与全量一致，不另起一套，避免二次迁移。
- **推后**：MySQL 栈起栈、其余 28 页、附件多模态、四渠道、MCP 双向、长期记忆、技能仓库、子智能体、场景包、定时任务、日报、计划模式、上下文压缩、编排预算、六场景全链路过审（只保输入侧）、RAG 指标基线、hybrid 与 Rerank（本周向量档）。

### 7.3 一周边界口径

RAG 本周只证明"检索能命中并给出处"，不承诺 §4.3 的指标基线（需语料与调参，属 A4）。若路由与专家编排未按期打通，演示退化为入口自答；**HITL 不退**，退则本周未验证最难机制。

## 10. 验收标准

### 10.1 一周验收

1. D1 三项前置就绪：云服务器可 SSH、域名证书生效、Milvus + etcd 起栈。
2. Sites 上可打开工作台并登录，HTTPS 下无混合内容报错、无 CORS 报错。
3. 演示故事端到端可演，且 HITL 拒绝路径与允许路径各演一遍。
4. 审计三页签能看到本轮真实数据（编排运行 / 工具明细 / 权限决策）。
5. 浏览器控制台无 error，无 4xx/5xx。

### 10.2 全量门禁（沿用手册 9.3）

双栈集成测试零失败；接口 e2e 全量零 FAIL；重建冒烟 + Nginx 重解析；日志 ERROR 归零 + 健康自检全绿；存量库升级须知。RAG 评测达 §4.3 基线。
