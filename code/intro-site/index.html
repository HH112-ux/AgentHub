全链路过审

写操作人工确认

高风险动作（改数据、对外发送、资金操作）必须人工批准，理由与置信度可见，决策全留痕。

密钥只在服务端

模型密钥、渠道凭据、MCP 请求头密文落库；生产环境命中出厂示例值拒绝启动。

可私有化部署

Docker Compose 一键拉起 PostgreSQL / MySQL 双栈，端口错开可并存，数据不出域。
